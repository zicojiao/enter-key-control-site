# Enter Key Control

Use **Enter for a new line** in supported ChatGPT, Claude, Gemini and DeepSeek chat editors. Send with **Ctrl+Enter** on Windows/Linux or **Command+Enter** on Mac.

[Install from Chrome Web Store](https://chromewebstore.google.com/detail/nllncjgkdkcabkomghcfgfaplgdnlcjo?utm_source=github&utm_medium=referral&utm_campaign=readme) · [Website](https://zicojiao.github.io/enter-key-control-site/) · [日本語](https://zicojiao.github.io/enter-key-control-site/ja/) · [简体中文](https://zicojiao.github.io/enter-key-control-site/zh-cn/)

| Key | Behavior |
| --- | --- |
| Enter | Add a new line |
| Ctrl+Enter | Send on Windows/Linux |
| Command+Enter | Send on Mac |
| Shift+Enter | Keep the website's native behavior |

Reload existing chat tabs after installation or an update. The popup shows current-page status and lets you pause globally or for one service. Features depend on your installed version; check the store for current availability.

Keyboard handling runs in your browser. Optional reports in version 2.6.0 and later are sent only when you choose Send report; the privacy policy explains what is sent and where it is stored.
