Desktop Chrome · AI chat shortcuts

New line? Just Enter.

Write multi-line prompts in supported ChatGPT, Claude, Gemini and DeepSeek chat editors. Press Enter to add another line, then send your finished message with Ctrl+Enter on Windows or Linux, or Command+Enter on Mac.

If you often send a message before you finish writing it, use a deliberate send shortcut while keeping plain Enter for paragraphs, lists, code and context.

YOUR KEYBOARD CONTROLS

  • Enter: add a new line.
  • Ctrl+Enter: send on Windows and Linux.
  • Command+Enter: send on Mac.
  • Shift+Enter: keep the website's normal behavior.

CONTROL WHERE IT RUNS

Enable or pause the extension globally, or pause it for an individual service. The popup shows the current page's status and offers a refresh button when the page needs the latest extension code. Your preferences are saved in Chrome storage.

GET STARTED

Install and enable the extension, then refresh AI chat tabs that were already open. Test Enter with a short draft before using the send shortcut. Compatibility depends on the page and editor, and websites may change their input controls.

WHY NOT JUST SHIFT+ENTER?

You can already use a site's native line-break shortcut. This extension is for people who prefer plain Enter to create new lines and a separate shortcut to send.

PRIVACY AND SUPPORT

Keyboard handling runs in your browser. The extension does not send your prompts to an external server or add external analytics. If an editor behaves unexpectedly, pause the extension for that service and use the store support hub to report the website, browser and affected shortcut. You do not need to include your conversation.

This independent extension is not affiliated with the AI services named above. Their accounts, subscriptions and regional availability are managed by each service.

Optional problem reports are sent only when you choose Send report. They include the details you provide and basic browser information, and are saved in a Google Form and emailed to the developer. Do not include private conversations. See the privacy policy for details.
