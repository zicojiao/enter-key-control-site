Get your shortcuts working.

  1. Use desktop Chrome on a configured AI chat website. This extension does not change native mobile apps.
  2. Open the extension popup. Check the current service, global switch, and per-service pause.
  3. Reload chat tabs that were already open when you installed or updated the extension. Save any unfinished text first.
  4. Try Enter with a short draft. It should add a new line. Ctrl+Enter sends on Windows/Linux; Command+Enter sends on Mac.
  5. If the behavior is unexpected, pause the extension for that service. Check for another extension that also changes keyboard shortcuts.

Tell us what happened

Use Report a problem in the extension if available in your installed version, or the store support hub. Include the service, browser, operating system, extension version, affected shortcut, and whether this happens in a new or existing conversation. Do not include passwords or private chat content.

In version 2.6.0 and later, reports are sent only when you press Send report. The details you enter and basic browser information are saved in a Google Form and emailed to the developer. Read the privacy policy before sending.
