Desktop Chrome guide

A new line in ChatGPT. A separate key to send.

When you are still writing a prompt, Enter should not have to mean you are finished. Here are two ways to add paragraphs in the desktop chat editor.

First, try the native shortcut

In the desktop ChatGPT composer, try Shift+Enter to insert a line break. This keeps the site's normal keyboard behavior and does not require an extension. These steps concern the text you type into the prompt box, rather than asking ChatGPT to format its answer.

Prefer plain Enter? Change the typing habit

Enter Key Control changes Enter to a new line in supported editors. Install the extension in desktop Chrome, enable it, then reload an existing chat tab. Try a short draft with two lines first. When ready, Ctrl+Enter sends on Windows and Linux; Command+Enter sends on Mac. Sending creates a real message in your chat account.

After an update, reload your chat tab

An already-open tab may still have the previous extension code. Check the extension popup for the current service and its status. Reload the page if prompted, then confirm that the global switch is on and this service is not paused. New chat views and embedded editors can behave differently.

If a keyboard shortcut behaves unexpectedly

Pause the extension for ChatGPT to restore the site's normal behavior. Check whether another keyboard extension is also changing Enter. When reporting a problem, include your browser, operating system, extension version, and whether it happens in a new or existing conversation. You do not need to share private prompt content.

Desktop browser and mobile app are different

This is a Chrome browser extension. It does not change the native ChatGPT phone app or your phone keyboard. The ChatGPT account, subscription, and availability are managed by OpenAI. Site updates can change compatibility; this guide does not claim every account or editor has been tested.
